# Sphere Volume Calculator

A simple, self-contained webpage built with HTML, CSS, and JavaScript to calculate the volume of a sphere based on user input. This project is designed as an assignment submission for the course **Full Stack Web Development (Subject Code: 21CSE354T)**.

## Features

- **Radius Input**: Accepts numerical values for the sphere's radius.
- **Output Area**: A secure, read-only text box that displays the computed volume.
- **Dynamic JavaScript Logic**: Calculates the volume in real time using the mathematical formula:
  \[
  V = \frac{4}{3} \pi r^3
  \]
  and displays it rounded to 4 decimal places.
- **Validation**: Prompts the user with an error alert if the entered radius is invalid or negative.
- **Clean Card Interface**: Centered layout utilizing standard CSS Flexbox and responsive styling.
