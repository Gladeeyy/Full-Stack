# 60-Second Countdown Timer

A simple, self-contained countdown timer webpage built with HTML, CSS, and JavaScript. This project is designed for a basic course assignment.

## Features

- **Prominent CSS Styling**: A clean, centered card interface with a modern look, featuring a bold blue countdown font and clear button controls.
- **Dynamic JavaScript Logic**: Real-time decrement of the timer using `setInterval()`, updating the view every second.
- **Controls**: Includes **Start**, **Pause**, and **Reset** buttons with active states and dynamic color feedback when time runs out.

## Project Structure

This project is completely self-contained within a single file:
- [index.html](file:///c:/Users/Sam/Documents/antigravity/wonderful-borg/index.html) - Contains the HTML markup, CSS styling (`<style>`), and JavaScript logic (`<script>`).

## How to Run

1. Simply double-click [index.html](file:///c:/Users/Sam/Documents/antigravity/wonderful-borg/index.html) or open it in any modern web browser (Chrome, Firefox, Edge, Safari, etc.).
2. Click the **Start** button to begin the 60-second countdown.
3. Use the **Pause** button to halt the timer temporarily, or **Reset** to return to 60 seconds
